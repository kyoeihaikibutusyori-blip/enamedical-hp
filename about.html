Philosophy

経営理念

Our Mission

地域に根ざし、
「気軽に相談できる薬局」であり続ける。

私たちエナメディカルは、函館市湯川町という地域に根を張りながら、ひとりひとりの患者様と長く向き合うことを大切にしています。 薬を渡す場ではなく、健康のことを安心して相談できる場であること。 そのために、薬剤師・医療事務スタッフ全員が、専門性とあたたかさの両方を備えて日々の業務にあたっています。

そして、これからの医療には、現場の知見をテクノロジーでつなぐ力が欠かせません。 私たちは医療DX事業を通じて、地域医療の課題解決に挑戦し続けます。

Values

私たちが大切にしていること

Core Values

Value 01

患者様第一

ひとりひとりの体調、生活、ご家族の状況。 目の前の方の事情を丁寧に聴き、安心と納得を届けることが、私たちの仕事のすべての起点です。

Value 02

地域密着

湯川町という地域の医療を支え続けることが、私たちの誇りです。 お一人で薬局に来られない方にも、薬剤師が直接お届けにあがります。

Value 03

未来への挑戦

これまでの薬局の枠を超え、医療DXという新しい挑戦へ。 現場で培った知見を、地域医療全体の改善につなげていきます。

History

沿革

Our History

2014年合同会社エナメディカル設立。函館市湯川町にて調剤薬局事業を開始。
2016年2店舗目を開設。地域での調剤・服薬指導体制を拡充。
2018年在宅医療・訪問配達サービスを本格展開。
2022年医療DX事業を立ち上げ、地域医療の課題解決に挑戦。
2025年医療DXソリューションのサービス展開を加速。
